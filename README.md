# 🎬 Studio Ghibli Movie App
### Aplicativo iOS desenvolvido com Swift e SwiftUI, focado na construção de uma experiência moderna de consumo de APIs e boas práticas de arquitetura no ecossistema Apple.
#### 📱 Visão geral
##### O Studio Ghibli Movie App é um projeto desenvolvido com o objetivo de consolidar conhecimentos em desenvolvimento iOS, explorando desde a camada de rede até a construção de interfaces reativas com SwiftUI.
##### A aplicação consome dados da API pública do Studio Ghibli, apresentando uma lista de filmes e permitindo a navegação para uma tela de detalhes com informações adicionais.

#### 🚀 Funcionalidades atuais
- Consumo de API REST com dados dos filmes
- Listagem dinâmica de filmes
- Navegação para tela de detalhes
- Interface construída com SwiftUI
- Organização de código visando escalabilidade e manutenção

#### 🔄 Em evolução
##### O projeto segue em desenvolvimento contínuo, com foco em aprimorar arquitetura, persistência de dados e cobertura de testes:
- Persistência local com UserDefaults para gerenciamento de favoritos
- Expansão do consumo da API:
  - Locais (Locations)
  - Personagens (People)
- Implementação de testes unitários
- Evolução para armazenamento mais robusto (ex: Core Data)

#### 🧰 Stack e conceitos aplicados
- Swift
- SwiftUI
- URLSession para networking
- Consumo de API REST
- Arquitetura baseada em separação de responsabilidades com MVVM
- Gerenciamento de estado em SwiftUI

#### 📡 API
##### Este projeto utiliza a API pública do Studio Ghibli:
##### https://ghibliapi.vercel.app/
